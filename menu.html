Заметки недели
⚡ Тренировки · водное поло
Завтрак — всегда плотный: орехи, молоко, сыр к любому блюду.
После тренировки ужин — в течение 30–60 мин.
Ср: кеджери — рыба + яйца + рис идеальное восстановление.
Пт: вонголе — белок моллюсков + ньокки, быстрые углеводы после нагрузки.
🧀 Кальций · без кисломолочного
К каждому завтраку — 30–40г твёрдого сыра (гауда / пармезан).
Сб: кекс с творогом — творог в выпечке ест ✓, хороший источник кальция и белка.
Вс: к фриттате — фета + сыр = двойной кальций.
Ср: к кедже́ри — тёртый пармезан сверху.
🩸 Железо · гемовое
Вт: болоньезе из говяжьего фарша — гемовое железо для Майи.
Добавить в соус побольше томатов + подать с зеленью (витамин С).
Сб: лобио в сациви — фасоль + болгарский перец обязательно.
🥗 Принцип тарелки · дефицит
Вт: болоньезе — паста ¼ тарелки, соус и зелень остальное.
Чт: соба — лапши немного, индейки и овощей больше.
Пт: вонголе — ньокки ¼, остальное соус и зелень.
🧄
Готовим заранее
Болоньезе (Вт): начать с утра или с вечера пн — соус тушить 1,5–2 часа.

Сациви (Сб): курицу варить с утра; ореховый соус — за 2 часа до подачи; подавать холодным.

Сибас (Вс): за 1–2 часа — оливковое масло + лимон + чеснок + тимьян. Надрезы на тушке.
Нутрициология недели
✓ Жирная рыба: кеджери с копч. скумбрией (Ср) — омега-3
✓ Рыбных ужинов: 3 из 7, не подряд (Ср, Пт, Вс)
✓ Красное мясо: болоньезе (Вт) — первый раз за 10+ дней
✓ Бобовые с витамином С: лобио + перец (Сб), чечевица (Сб–Вс)
✓ Белок в каждом ужине
✓ Грецкие орехи: сациви + завтраки — магний для тренировок
✓ Творог в выпечке (Сб) — кальций и белок для всех ✓
