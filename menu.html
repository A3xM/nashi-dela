Заметки недели
⚡ Тренировки · водное поло
Завтрак — всегда плотный: орехи, молоко, сыр к любому блюду.
После тренировки ужин — в течение 30–60 мин.
Пн: форель после тренировки — белок + омега-3, идеально.
Брать бутылку воды в бассейн: потоотделение незаметно.
🧀 Кальций · без кисломолочного
К каждому завтраку — 30–40 г твёрдого сыра (гауда / пармезан).
Ср: к блинчикам — без сметаны. Мёд + орехи.
Ср: к лингвини с мидиями — тёртый пармезан щедро.
Вт: кунжут на тостах — дополнительный кальций.
🩸 Железо · нут
Чт: карри с нутом — добавить болгарский перец или выдавить лимон.
Витамин С улучшает усвоение железа из бобовых.
🥗 Принцип тарелки · дефицит
Вт: стир-фрай с соба — лапши ¼ тарелки, овощи остальное.
Ср: лингвини с мидиями — пасты меньше, добавить цукини.
Вс: тикка-масала — риса ¼ тарелки, курицы и зелени больше.
🧄
Маринуем заранее
Свиная шея (Сб): с пятницы вечером — соевый соус + мёд + горчица + чеснок.

Форель (Пн): за 30–60 мин — оливковое масло + лимон + тимьян + каперсы.

Тикка-масала (Вс): с вечера субботы — йогурт + карри + куркума + имбирь + чеснок.

Дорада (Пт): за 1–2 часа — оливковое масло + лимонная цедра + чеснок + петрушка, надрезы на тушке.
Нутрициология недели
✓ Жирная рыба: форель (Пн) — омега-3
✓ Морепродукты: мидии (Ср), креветки в том-яме (Пт)
✓ Рыбных ужинов: 2 из 7, не подряд
✓ Бобовые с витамином С: нут + перец/лимон (Чт)
✓ Белок в каждом ужине
✓ Яичных завтраков: 2 из 7
